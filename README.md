# 多益備考 TOEIC PLANNER

個人用的 TOEIC 備考網頁 App：繁體中文介面、英文題目。目前範圍是閱讀 Part 5–7。

網址：https://coldedge23.github.io/toeic-planner/

架構與決策紀錄：[docs/20261010_TOEIC備考App架構計畫_v2.md](docs/20261010_TOEIC備考App架構計畫_v2.md)

## 架構摘要

- 純前端：Vite＋React＋TypeScript，靜態部署，電腦與手機共用同一個網址。
- 資料存在瀏覽器的 IndexedDB（Dexie）。電腦與手機的紀錄**不會自動同步**，需要用 JSON 備份手動搬移。
- 題庫來源：Google 試算表發佈成 CSV，App 只匯入狀態為「已審核」的題目。
- AI 出題由 Google Apps Script 執行（每天 06:00 自動出題，或從 Sheet 選單手動出題）；App 內不存放任何 API 金鑰。

## 開發

Windows 可直接雙擊專案根目錄的 `啟動本機網站.cmd`，準備好後會自動開啟 `http://localhost:5173/`。使用期間保留啟動視窗，結束時按 Ctrl+C。固定使用 5173；若已被占用，會顯示錯誤，不切換其他連接埠。本機與 GitHub Pages 的學習資料各自獨立。

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 單元測試（Vitest + fake-indexeddb）
npm run typecheck
npm run build      # 輸出到 dist/
npm run preview:pages  # 以 /toeic-planner/ 為根路徑建置並預覽（模擬 GitHub Pages）
```

## 部署（GitHub Pages）

推送到 `main` 後，`.github/workflows/deploy.yml` 會自動：安裝套件 → 執行測試 → 以 `/<repo 名稱>/` 為根路徑建置 → 部署到 `https://<帳號>.github.io/<repo 名稱>/`。測試沒過就不會部署。

第一次需在 GitHub repo 的 Settings → Pages → Build and deployment → Source 選「GitHub Actions」。

## 手機使用

- 用手機瀏覽器開啟網址後，「加入主畫面」即可像 App 一樣開啟（PWA），開過一次後離線也能作答。
- 電腦與手機的紀錄各自獨立，換裝置時用「設定 → 備份與還原」搬移。

## 資料保護（2026-10-12）

- 修改文章時，匯入檔需包含同組所有仍在使用的題目，並把這些題目的 `version` 加 1；缺題或未升版時，文章與同組已審核題目一併略過，預覽會顯示原因。明確改成草稿／退回的題目仍可下架。
- 內建 demo 只補入缺少的資料，不覆寫既有題目、版本、下架狀態或文章。
- JSON 匯出使用單一唯讀交易，避免跨分頁交卷造成不同資料表的時間點不一致。還原前檢查重複識別碼、計畫／題組／測驗／作答／錯題關聯及交卷完整性。
- 在設定頁確認還原時，先啟動「還原前」JSON 備份下載，再套用備份。請確認瀏覽器下載成功並保存檔案；瀏覽器阻擋下載或未保存檔案時，App 無法保證本機檔案已落盤。
- Part 6 題幹留白時，在讀取完整題組及建立測驗快照時固定空格編號；錯題重考不依篩選後的順序重新編號。自行匯入的題目也可在題幹明確填 `[1]`、`[2]` 等原始空格編號。

## 今日任務與練習（2026-10-12）

- 今日與落後任務可按「開始練習」，先查看對應 Part 的建議題數，再開始作答。題數依任務分鐘估算（Part 5／6／7 每題約 45／60／90 秒），完整文章題組不拆開；題庫不足時顯示可練習題數，無題可用時不能開始。
- 任務練習固定對應單元，題數與時限可以調整；自由練習請從模擬考頁直接開始。已有未交卷測驗時先續答原測驗，不改變原任務關聯。
- 暫停、續答與重新整理保留任務關聯。交卷後按「確認完成任務」才更新今日進度，也可選「稍後再完成」或在今日／計畫頁手動勾選、取消勾選。
- 重排後的舊任務不會誤標記新任務；已完成且保留到新計畫的任務仍維持原識別碼。
- IndexedDB 與 JSON 備份升至 v3。v1／v2 JSON 備份依序遷移；舊測驗的任務關聯設為空，不猜測歷史對應。v3 備份需使用新版 App 還原。

## 單字練習第一階段（2026-10-12）

已新增自編 500 個職場單字／片語入門包（十個主題、每個 50 筆，可選主題預覽後加入），以及 CSV 範本下載、批次匯入與錯誤行號。預覽可搜尋並以每頁 50 筆顯示；搜尋不改變確認匯入的整批範圍。原版 100 筆內容保留，已加入原版者只補入缺少的 400 筆；重複單字略過，有錯誤不寫入，保留既有釋義與複習進度。操作與驗收見 [單字入門包與批次匯入](docs/20261012_單字入門包與批次匯入.md)，新版驗收見 [500筆擴充](docs/20261012_單字入門包500筆擴充.md)。

- 作答頁、文章與檢討頁可先選取英文，再按收錄；手機也可按「收錄單字」後輸入。確認繁中意思才儲存，保留例句與當時題目／文章快照。
- 單字本可手動新增、搜尋與編輯。大小寫、前後／連續空白與全形視為同字，重複新增不覆蓋；同字多義可補在既有意思欄。
- 今日頁顯示到期字、新字與今日練習數，沒有讀書計畫也可使用。預設到期字上限20、新字上限5，可調整為1–100及0–30。
- 到期字先於新字。翻面前不顯示釋義與單字清單；翻面後用「不熟／有印象／熟悉」評定，不換算官方成績。
- 排程是本App簡單規則：不熟1天、有印象至少3天且以原間隔1.5倍延長（上限30天）、熟悉至少7天且以原間隔2倍延長（上限60天）。日期依Asia/Taipei。
- 當天已評定的字不重複出現，離開／重整保留已寫入紀錄；新增與編輯不改既有複習進度，跨頁更新衝突會提示重新開啟。
- IndexedDB及JSON備份升為v4，新增單字、複習與每日設定三張表。v1–v3備份遷移成空單字本，保留舊學習紀錄；v4備份要用支援v4的App還原。原schema3回復套件不能直接回復已升級v4的裝置。
- 單字本與來源快照均納入JSON備份；第一階段不呼叫AI，例句填空與發音留待第二階段。

## Part 2 通勤聽力第一版（2026-10-14，本機）

- 側欄「聽力練習」提供 30 題自編 Part 2 應答問題，美式英語合成音訊。
- 搭車作答：5／10／15 題，預估 5／10／15 分鐘；隨機抽題不重複，完整播放後選 A／B／C，作答後才顯示逐字稿與繁中解析。可只練聽力錯題。
- 連續收聽：按完整題目切成不超過 5／10／15 分鐘的單段音檔；包含五秒思考停頓、英文答案與英文解說，不計入正確率或錯題。第一版依題號順序播放，各時長從第 1 題開始。
- 出門前下載完整題包。完整檔案通過 SHA-256 驗證後存到 Cache Storage，已下載檔案使用 Blob URL 播放與跳轉；下載中斷後可繼續。音訊不在 JSON 備份內，換裝置需重新下載。
- 聽力紀錄透過 Repository 保存；v5 新增獨立 listening_sessions 表。v1–v4 備份遷移保留閱讀／單字資料，新增空聽力表。還原仍是取代，不是合併。
- iPhone 請手動按播放。鎖屏、切換 App、來電、耳機控制與實際離線使用需實機驗收；桌機瀏覽器驗證不等於 iPhone 驗收。
- 本機音訊產生腳本：`scripts/generate-listening-audio.ps1`（Windows Zira、Python 3、lameenc）。成品已放在 public/audio，不需使用者生成。音檔、manifest 與題目必須一起升版，不可只改正解。

操作、驗證與上線前備份要求見 [Part 2 聽力驗收](docs/20261014_Part2聽力驗收.md)。

## 可選且分別下載的聽力題包（2026-10-14，本機）

現有 30 題分為「資訊問答」14 題、「職場互動」10 題、「間接回應與確認」6 題。練習設定先選包，搭車模式與錯題只從該包抽題；連續收聽依包提供完整音檔，短包明示實際時長，不重複湊滿 5／10／15 分鐘。

每包獨立下載、重試與移除，列表顯示大小、版本及實際下載狀態。移除只清音訊，保留全部學習紀錄，進行中的題包有移除保護。舊單題與整包音檔保留供 v5 續練；各新包可沿用舊單題，下載後複製到獨立快取。資料庫與 JSON 不升版，仍為 v5。

題包定義、音訊產出及驗收見 [Part 2 題包管理](docs/20261014_Part2題包管理.md)。本機瀏覽器驗收改用 `scripts/verify-listening-packs-browser.py`。

## 使用限制

- 清除瀏覽器網站資料會讓學習紀錄消失，請定期到「設定 → 備份與還原」匯出 JSON 備份。備份不含音訊與圖片檔。
- 正確率不會換算成多益官方分數。
- demo 題庫是原創練習題，不是 ETS 官方試題。
