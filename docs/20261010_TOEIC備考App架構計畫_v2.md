## 2. 架構

```
┌──────────── Google（內容管線）─────────────┐
│ 題庫 Sheet  ←  Apps Script                   │
│   │            ├ 每天 06:00 自動出題          │
│   │            ├ 選單「AI 出一批」手動出題    │
│   │            └ 金鑰存在指令碼屬性           │
│   └ 發佈成 CSV 網址                          │
└──────────────┬────────────────────────────┘
               │ 讀取 CSV → 預覽 → 確認後寫入（只收「已審核」）
┌──────────────▼──── 備考 App（純前端、靜態部署）┐
│ 設定／計畫／今日／模擬考／錯題本／題庫          │
│ IndexedDB：設定、計畫、作答、錯題、題庫快取      │
│ JSON 備份匯出／匯入（換裝置時手動搬資料）        │
└────────────────────────────────────────────────┘
```

- **App 不放任何 API 金鑰**：設定頁不提供金鑰欄位，AI 呼叫只在 Apps Script 裡執行。
- **前端技術**：Vite＋React＋TypeScript、React Router、Dexie（IndexedDB）、Zod、Recharts。不需要伺服器，所以改用 Vite，不用 Next.js。
- **部署**：靜態網站託管，平台待選（見第 6 節）。另外做成 PWA，手機可以加到主畫面，離線也能作答。
- **既有程式沿用**：`src/domain/schema.ts`、`dates.ts`、`settings.ts` 與框架無關，可以直接沿用。

## 3. 限制（要先知道）

1. **電腦和手機的學習紀錄不會自動同步。** 每台裝置各自存在自己的瀏覽器裡；要搬資料就用 JSON 備份匯出再匯入。自動跨裝置同步列在後續階段（Supabase）。
2. **發佈成 CSV 的網址是公開的。** 拿到網址的人都能讀取題目內容。題庫 Sheet 只放原創練習題，不放個人資料。
3. **App 的網址是公開的。** 別人開啟只會看到空白的 App，看不到你的紀錄，因為紀錄只存在各自的瀏覽器。
4. 清除瀏覽器網站資料會讓紀錄消失；建議定期匯出 JSON 備份。

## 4. 題庫 Sheet 欄位

第一列放欄位名稱，第二列開始每列一題。欄名用英文 key，也接受中文欄名（ID、單元、難度、題組、文章、題目、選項A–D、正確答案、解析、標籤、狀態、版本、建立日期），所以照提示詞包建立的 Sheet 也能讀。（P5 實作後更新）

| 欄位 | 必填 | 規則 |
|---|---|---|
| id | 是 | 不可重複，格式 `P5-0001`、`P6-0001`、`P7-0001` |
| part | 是 | 5、6 或 7 |
| difficulty | 是 | 基礎／中階／進階 |
| group_id | Part 6／7 必填 | 同一篇文章的題目用相同 group_id，例如 `P7-G001` |
| passage | Part 6／7 必填 | 文章全文；同一 group_id 只需在其中一列填寫，其餘留白。多篇文章（Part 7）用單獨一行 `---` 分隔 |
| question | Part 5／7 必填 | 題幹；Part 6 可填空格編號（例如 `[2]`）或留白，空格在文章內標成 `[1]`、`[2]` |
| a, b, c, d | 是 | 四個選項 |
| answer | 是 | A／B／C／D |
| explanation | 是 | 繁體中文，說明正解原因與錯誤選項的陷阱 |
| tags | 否 | 用分號分隔，例如 `詞性;時態` |
| status | 是 | 草稿／已審核／退回；App 只匯入「已審核」 |
| version | 否（預設 1） | 正整數；修改已審核題目時加 1，App 才會更新；版本沒加 1 的修改會被略過並提醒 |
| created_at | 否 | YYYY-MM-DD |

匯入規則：任何一列有錯誤時整批不寫入；Sheet 上改成「草稿」或「退回」的題目，App 會下架；過去測驗的結果使用當時的題目快照，題目改版不影響歷史紀錄。

## 5. Apps Script 規格（P7 已實作：`apps-script/Code.gs`）

- 每天 06:00 由時間觸發條件執行，加上「AI 出一批」自訂選單，可選單元與難度。
- 新題目寫在最後一列，ID 接續現有編號。狀態預設填「草稿」。
- 自動審核（2026-10-10 使用者確認）：「設定」分頁的「自動審核」填「是」時，出題後請 AI 只看題目與選項再作答一次；答案與正解一致的題目直接寫成「已審核」，不一致的維持「草稿」（Part 6／7 一篇有一題不一致就整篇維持草稿）。複核失敗時全部維持草稿。App 匯入仍保留預覽確認，不自動匯入。
- 新題目的題幹要和現有題目比對，重複的不寫入。另外檢查四個選項齊全、正解在選項中、解析不空白；不合格的題目不寫入，記在「執行紀錄」分頁。
- 每次執行的題數上限：自動出題 10 題、手動出題 15 題。另設每日總題數上限，避免費用失控。
- 金鑰只存在「指令碼屬性」，程式碼裡不寫金鑰。
- AI 服務（2026-10-10 使用者確認）：每日自動出題預設用 Google Gemini API 免費額度；高品質批次由 Claude Code 對話直接產生 CSV 匯入。程式可在「設定」分頁切換成 Claude API。
- 非機密設定（每日題數、單元輪替、難度、上限、模型）放在試算表「設定」分頁，可直接修改。
