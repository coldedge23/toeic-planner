# 單字入門包與批次匯入

## 使用方式

雙擊專案根目錄 `啟動本機網站.cmd`，在瀏覽器開啟本機單字本。已開啟的網站可重新整理。

### 加入入門包

1. 單字本 →「選擇入門包」。
2. 勾選主題，再按「預覽入門包」。
3. 檢查釋義、詞性、例句，以及新增／略過狀態。
4. 按「確認加入」後才寫入。單字本仍為空的使用者也不會被自動灌入資料。

入門包 v2 共 500 個單字／片語，十個主題各 50 筆：辦公與文件、會議與專案、人事與招募、採購與合約、財務與帳務、物流與配送、旅遊與住宿、顧客服務、行銷與市場、設施與維護。內容為自編職場閱讀入門素材，英文例句為本專案原創；非官方題庫、必考清單或單字頻率統計。使用者可在加入後修改意思與例句。

原版 100 筆字義與例句完整保留，僅調整部分詞條的主題分類。已加入原版者再預覽整包，會顯示新增 400、略過 100；若另有手動新增的同字，實際新增數會更少。既有識別碼、個人編輯與複習進度不變。

大量預覽可用英文或中文意思搜尋，每頁最多 50 筆；換頁會回到清單頂端。搜尋及分頁只影響畫面顯示，「確認加入」仍處理整批選定主題的資料；若只想加入特定主題，請先調整主題勾選。

較易混淆的字義抽查參考（查證日期 2026-10-12）：

- inventory：庫存／存貨清單，[Cambridge Dictionary](https://dictionary.cambridge.org/dictionary/english/inventory)。
- reimbursement：費用償付／報銷款，[Cambridge Business English 的 reimburse 條目](https://dictionary.cambridge.org/us/dictionary/english/reimburse?topic=paying-money)。
- itinerary：旅行行程／行程表，[Oxford Learner's Dictionary](https://www.oxfordlearnersdictionaries.com/definition/english/itinerary)。
- freight：運輸中的貨物／貨運，[Cambridge Dictionary](https://dictionary.cambridge.org/dictionary/english/freight)。

上述是字義參考，不是整包來源；沒有複製來源例句，亦未宣稱逐筆完成外部審核。

### CSV 批次匯入

1. 按「下載 CSV 範本」，保留標題列，修改兩筆示例或新增自己的內容。
2. 按「CSV 批次匯入」選擇檔案。
3. 若有錯誤，依行號修正並重新上傳；整批不寫入。
4. 檢查預覽與新增數，再按「確認加入」。

| 英文欄名 | 可接受中文欄名 | 必填 |
|---|---|---|
| term | 英文單字／片語 | 是 |
| meaning_zh | 繁中意思 | 是 |
| part_of_speech | 詞性 | 否 |
| example | 英文例句 | 否 |

可省略選填欄，欄位可換順序。一次最多 1,000 筆、2 MB；使用 UTF-8 CSV（可有 BOM），支援欄位內逗號、換行與雙引號跳脫。中文錯誤行號是檔案的實體行號，包括空行與跨行例句。其他欄名、重複欄名、缺必填欄、錯誤引號與錯欄數會阻擋，不把測驗題庫 CSV 當成單字清單。

範本含 UTF-8 BOM，方便 Excel 2016 辨認中文。Excel 儲存成一般 CSV 時可能改成系統編碼；若 App 顯示編碼錯誤，使用記事本開啟檔案確認中文正確後，另存為 UTF-8 再上傳。CSV 是純文字，沒有字型設定。

## 資料保護

- 兩個入口使用同一個 Repository 批次新增方法；確認前不寫入。
- 單字正規化後比對重複；已存在或本批重複的單字略過，保留識別碼、意思、來源快照、下次複習日與歷次紀錄。多義請編輯既有單字。
- 預覽會隨既有單字更新；確認交易內再次比對，避免其他分頁剛新增同字。結果以實際新增／略過數為準。
- 全批重新驗證後使用單一交易，寫入錯誤會回滾；新字加入今日新字佇列，沿用每日上限，不改使用者設定。
- 沿用 IndexedDB v4、JSON schema v4，沒有新增資料欄或備份版本。新增單字完整納入既有備份／還原。
- 本機與 GitHub Pages 是不同來源，學習資料各自獨立。本輪未 commit、push 或部署。
