# 單字練習第一階段

日期：2026-10-12（Asia/Taipei）
範圍依本次使用者確認：題目收錄、手動新增、單字卡與每日複習。沿用v2架構及既有UI，純前端、Repository、IndexedDB；不新增後端或API金鑰。

## 使用流程

1. 作答頁、文章或逐題檢討選取英文，按「收錄」；手機可直接按「收錄單字」後輸入。確認繁中意思，詞性與例句選填。
2. 單字本可新增、搜尋、編輯，保留原題目與文章快照。重複英文以大小寫、全形與空白正規化判定，不覆蓋既有資料；多義可補在原意思欄。
3. 今日頁或單字本開始每日複習。先到期字、再新字；預設20個到期字與5個新字，可調整。
4. 先回想、翻面看解釋及例句，再按不熟／有印象／熟悉。翻面前釋義與單字清單隱藏，避免直接看到答案。
5. 離開、重整後已評定紀錄保留，未評定的不算完成；每個單字每天最多評定一次。每日量用完可以增加上限或明天繼續。

## 排程與資料

- 不熟：1天；有印象：至少3天、舊間隔1.5倍向上取整、上限30天；熟悉：至少7天、舊間隔2倍、上限60天。這是App規則，不是官方分數或熟練度認證。
- 所有日期以Asia/Taipei計算，長時間開著及從背景回來會更新今日日期。
- 單字、複習紀錄、每日量設定共三張新表；IndexedDB version(4)與upgrade，既有題庫、測驗、答案與任務保留。
- JSON SCHEMA_VERSION=4；v1–v3依序遷移成空單字表，v4備份包含單字來源與複習設定。還原前保留目前資料的下載備份，失敗交易回滾。
- 寫入採交易、唯一單字索引；評定重送冪等，跨頁編輯／複習衝突會擋下；備份檢查單字唯一性、複習來源、次數、日期及最新排程一致性。
- 單字成績與原測驗、任務完成分開，不自動勾選讀書任務。
