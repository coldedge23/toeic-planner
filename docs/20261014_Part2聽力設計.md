# Part 2 通勤聽力第一版

## Direction contract
THESIS：在通勤中完成一小段聽力；操作集中在播放與 A／B／C 作答。
OWN-WORLD：沿用現有深海軍藍側欄、米白底、細邊框矩形與 Noto Sans TC／Jost。
STORY：選時間與模式、下載題包、聽題；搭車作答後看解析，連續收聽不計分。
FIRST VIEWPORT：頁首說明、離線狀態與練習設定；練習中播放控制在選項上方，逐字稿只在已作答後出現。
FORM：延伸現有操作型介面；三個等寬大選項，手機縱向排列，不改造既有頁面。
FINISH：桌機與 360px 操作驗證、測試與型別檢查、建置與資料保留驗證；iPhone 鎖屏／切換 App 留待實機。

使用者已確認：iPhone、大眾運輸 80%／開車 20%、Part 2、30 題原創音訊、5／10／15 分鐘、兩種模式、離線與續練。直接依現有介面製作。

## 題包管理擴充（2026-10-14 使用者確認）

THESIS：選擇本次通勤的題包，只下載需要的音訊，保留原作答與續練。
OWN-WORLD：沿用既有海軍藍／米白、矩形細邊框與字體，不更換全站視覺。
STORY：先選題包、時間與模式開始練習；下載、重試與移除集中在下方列表。
FIRST VIEWPORT：選包及目前下載狀態放在練習設定上方；練習中播放器置頂，不讓完整下載清單擋住作答。
FORM：既有操作頁延伸，以單一題包列表與情境設定呈現；手機設定單欄，操作按鈕至少 48px。
FINISH：桌機／360px 圖片複查、根路徑及 GitHub Pages 子路徑的離線操作、舊 v5 續練、下載／移除保留資料均驗證；正式部署與 iPhone 實測另行確認。

不增加題目，不改 v5 學習紀錄格式；保留舊版整包音訊與清單供舊練習續用。短題包明示實際時長，不重複湊時間。
