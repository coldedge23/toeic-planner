## 使用

1. 從側欄「聽力練習」或今日頁「開始聽力練習」進入。
2. 通勤前連網，按「下載離線題包」，等待「音訊已完整下載，可離線播放」。33 個 MP3（30 個單題、3 段連續音訊）合計約 17.0 MiB；下載檢查完整檔案 SHA-256。下載中斷可重試，不影響紀錄。
3. 搭車選「搭車作答」：時間為估計，5／10／15 題隨機抽題，可改選聽力錯題。完整播放問句與 A／B／C 後開放作答，作答後顯示英文逐字稿與繁中解析；不強制倒數交卷。
4. 開車前選「連續收聽」，按開始後手動按播放器播放。每題包含五秒思考停頓、英文答案與英文解說，途中不需操作。5／10／15 分鐘題包分別 9／18／28 題，約 4:47／9:38／15:00；按完整題目切段、不截斷解說，皆由第 1 題依題號開始。剩餘兩題仍可在搭車作答模式練習。
5. 搭車的答案立即保存，重新整理後仍可看解析或到下一題。連續收聽約每五秒／暫停時保存位置，非正常關閉可能回到上一保存位置。連續音檔播完自動結束，不計分。
6. 待複習聽力錯題按「最近一次作答仍答錯」判定；答對後移出待複習。只聽不影響錯題。聽力與閱讀分開統計，資料不足時不重複抽題。

## 資料保護

- 資料庫及 JSON 備份為 v5；新增獨立 `listening_sessions`，不改舊版 schema，不將 Part 2 混入閱讀 ACTIVE_PARTS／排程／匯入。
- v1–v4 JSON 遷移成空聽力表，保留原閱讀與單字資料。v5 備份要使用支援 v5 的 App 還原，舊版 App 無法直接讀取 v5 資料庫。
- JSON 包含聽力題目快照、作答、進度；音訊檔不在 JSON 內。換裝置要重新下載音訊，資料仍以還原取代而非合併。
- 備份先驗證重複作答、快照與進度關係；錯誤還原不修改原資料。續練修改使用 revision 防止跨頁覆寫。
- 瀏覽器可能清除快取；「已下載」依實際檔案檢查，不是永久承諾。不要清除網站資料。試用預覽的 origin 與正式網站各自獨立。

4. 若 iPhone 背景中止，回到練習頁按播放；第一版不保證在所有 iOS 設定下背景持續播放。

## 音訊來源與重建

題目與解析均為本專案自編，非官方／網路試題。英語使用 Windows 安裝的 Microsoft Zira Desktop（en-US）生成，不需金鑰，無上傳。

`scripts/generate-listening-audio.ps1` 產出 WAV 後由 Python `lameenc`（本次 1.8.4）編成單聲道 64kbps MP3。開發重建需先安裝到 `node_modules/.audio-tools`，再執行腳本。一般使用與建置直接使用已生成的靜態音檔，不需要 Python、Windows 語音或任何線上語音服務。若修改題目／音訊須一起新增題包版本與 manifest，不能以舊音檔配新正解。

相容性依據：[Apple 音訊文件](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/Using_HTML5_Audio_Video/)、[Workbox 媒體快取說明](https://developer.chrome.com/docs/workbox/serving-cached-audio-and-video)。本版使用完整快取 Blob 播放以避免離線 Range 請求，但背景播放仍以實機驗收為準。
