## 音訊產製

沿用 Microsoft Zira Desktop（en-US）、語速 -1、16kHz／16-bit／單聲道 WAV 與 64kbps MP3；每題收聽包含五秒思考及兩秒轉場。一般建置直接使用靜態 MP3，無線上語音 API 或金鑰。

Windows 本機產製：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/generate-listening-batch2.ps1`，再執行 `python scripts/encode-listening-packs.py`。需已安裝 Microsoft Zira、Python 及 `node_modules/.audio-tools` 中的 lameenc 1.8.4。

第二批產製腳本只使用新題目及新音訊目錄；既有 WAV 沿用，不默默重新合成。manifest 記錄題目來源 SHA-256，題目變更時停止使用既有版本；音檔或 manifest 內容不同也拒絕覆寫，需新增題號／音訊及題包版本並保留舊資產。第一批 `generate-listening-audio.ps1` 仍只處理原始 30 題。
