## 操作

1. 從「聽力練習」的題包下拉選單或列表「選用此包」選擇主題。
2. 下方列表顯示題數、大小、版本與狀態：尚未下載、部分下載、完整下載。使用 HTTPS 網址或 localhost；瀏覽器不支援離線儲存時會顯示提示。
3. 選包後只抽該包的已審核題目。錯題來源只列入該包最近一次答錯的題目；短包不重複抽題。
4. 按「下載此題包」或列表下載鈕。逐檔驗證完整 bytes／SHA-256，失敗保留已完成檔案；重試只抓缺失或損壞檔案，不下載其他題包。
5. 「移除音訊」只刪該包的音訊快取與對應舊版單題快取副本，保留所有題目快照、作答、錯題、閱讀、單字及備份紀錄。其他已下載題包仍可離線使用。
6. 進行中的練習使用的題包不能移除；Repository 也檢查進行中紀錄，避免另一分頁刪除所需音訊。可下載缺少的音訊後重試續練；進度不重設。
7. 有舊版快取或舊版進行中練習時，顯示「舊版整包音訊」。可補下載供舊練習續用；所有練習結束後，使用者可明確移除此舊快取。新包下載會把有效舊單題複製到各包，移除舊快取不影響已完整下載的新包。

## 相容性與資料

- 資料庫與 JSON **維持 v5**，沒有新增欄位、還原、重匯入或自動重排。題包目錄與下載狀態不寫入 IndexedDB；狀態從實際 Cache Storage 檔案重新驗證。
- 題包有固定 id／version，使用獨立快取。下載及移除不改變學習資料。舊單題與舊連續音檔、manifest 保留在網站。
- 續練依 question_snapshot 的題號、版本、順序選取原音訊；舊整包連續收聽不會被換成新包。找不到匹配音訊時顯示錯誤，保留紀錄，不猜測或替換。
- 舊跨題包作答仍保留，錯題可在相應新包找到。JSON 備份仍不含音訊，換裝置需重新下載。
- 網站子路徑使用 BASE_URL，離線播放用驗證後的 Blob URL，避免依賴網路 Range 請求。

## 開發與擴充

- `src/fixtures/listening-packs.json`：固定題包 id、version、標題、描述與題號清單。
- `scripts/encode-listening-packs.py`：沿用原單題檔與既有 WAV，按每包的完整題目組成 5／10／15 分鐘內音檔，產出 `listening-pack-audio.json`。
- `src/domain/listening-packs.ts`：純函式的選包、題目篩選及音訊順序判斷。
- `src/storage/listening-pack-audio.ts`：媒體目錄、SHA-256、各包下載、快取移除與舊版音訊解析；畫面透過 Repository 使用。
- 原音訊與題包版本不可原地覆寫；兩個音訊編碼腳本遇到既有版本的音檔內容變動會停止。新增內容需使用新題號／題包版本與音訊目錄，並保留原版資產及清單供舊練習續用。若修改單題內容，題目與單題音訊都要另行升版，不能僅更換包名沿用舊 MP3。
- 本次只建立三個 v1 題包，未新增一般使用者上傳或自動 AI 出題管理功能。
