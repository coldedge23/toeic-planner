# 多益題庫 AI 出題：設定步驟

`Code.gs` 貼在「多益題庫」試算表裡執行。功能：

- 每天 06:00–07:00 之間自動出題（預設 10 題，依「設定」分頁輪替 Part 5／6／7）
- 選單「AI 出題 → 出一批題目…」手動出題（每次最多 15 題）
- 新題目一律寫成「草稿」；格式不合、選項重複、與既有題目重複的題目不寫入，原因記在「執行紀錄」
- 同一天自動加手動最多寫入 30 題（「設定」分頁可改）

預設使用 Google Gemini API 的免費額度。金鑰只存在 Apps Script 的「指令碼屬性」，不寫在程式碼或試算表裡。

## 1. 申請 Gemini API 金鑰（免費）

1. 開啟 https://aistudio.google.com/apikey ，用你的 Google 帳號登入。
2. 按「Create API key」（建立 API 金鑰），複製產生的金鑰。
3. 金鑰等同密碼，不要貼到聊天、試算表或任何公開的地方。

免費額度的上限會變動，以 AI Studio 帳號頁面顯示的為準。免費版送出的內容可能被 Google 用來改進產品；本程式送出的只有出題指令與既有題目的開頭，不含個人資料。

## 2. 貼上程式碼

1. 開啟「多益題庫」試算表 → 上方選單「擴充功能」→「Apps Script」。
2. 左側 `程式碼.gs`（或 `Code.gs`）裡的預設內容全部刪掉，貼上本資料夾 `Code.gs` 的全部內容。
3. 按儲存（磁碟圖示），專案名稱可以填「多益題庫出題」。

## 3. 存入金鑰

1. Apps Script 左側齒輪「專案設定」→ 拉到最下面「指令碼屬性」→「新增指令碼屬性」。
2. 屬性：`GEMINI_API_KEY`，值：剛才複製的金鑰 → 儲存。

改用 Claude API 時：新增 `CLAUDE_API_KEY`，並把試算表「設定」分頁的「AI 服務」改成 `claude`。

## 4. 第一次執行與授權

1. 回到試算表，重新整理頁面。上方會多出「AI 出題」選單（可能要等幾秒）。
2. 「AI 出題」→「檢查設定」。第一次會要求授權：選你的帳號 → 若出現「Google 尚未驗證這個應用程式」，按「進階」→「前往 多益題庫出題（不安全）」→「允許」。這是你自己的程式，只存取這份試算表與 AI 服務。
3. 確認「金鑰：已設定」。
4. 「AI 出題」→「出一批題目…」→ 選 Part 5、題數 3 → 出題。完成後「題庫」分頁會多出 3 列草稿，「執行紀錄」會記一筆。

## 5. 開啟每天自動出題

「AI 出題」→「開啟每天 06:00 自動出題」。要停止就按「停止每天自動出題」。

## 6. 審核題目

逐題檢查題目、選項、answer 與解析。確認無誤後把 `status` 改成「已審核」；有錯的改成「退回」。修改已審核的題目時，把 `version` 加 1。

## 7. 讓 App 讀到題庫

1. 試算表上方「檔案」→「共用」→「發布到網路」。
2. 「連結」分頁：左邊選「題庫」工作表，右邊選「逗號分隔值 (.csv)」→「發布」→ 確認。
3. 複製產生的網址，貼到 App「設定 → 題庫來源」並儲存。
4. 之後在 App「題庫」頁按「重新載入」，預覽無誤後確認匯入。只有「已審核」的題目會進入題庫。

發布後的網址任何人拿到都能讀取「題庫」分頁的內容；這張表只放題目，不要放個人資料。Google 會在你修改試算表後自動更新發布內容，可能有幾分鐘延遲。

## 疑難排解

| 狀況 | 處理 |
|---|---|
| 「執行紀錄」顯示 Gemini API 錯誤 404 或找不到模型 | 模型名稱已變更。到 AI Studio 查目前可用的 Flash 模型名稱，填到「設定」分頁的「模型」 |
| 錯誤 429 | 超過免費額度，隔天再試，或把「每日題數」調低 |
| 錯誤 400／403 | 金鑰錯誤或未啟用，重新建立金鑰並更新指令碼屬性 |
| 寫入 0 題、略過很多 | 看「執行紀錄」的略過原因；多半是格式不合或與既有題目重複 |
| 沒有「AI 出題」選單 | 重新整理試算表；仍沒有就到 Apps Script 手動執行一次 `onOpen` |
